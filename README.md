### 🧠 Featured Project

#### [CodeCite](https://github.com/Tarun-379/CodeCite) — RAG-based codebase Q&A with file & line citations
Ask natural-language questions about any local or GitHub repo and get answers grounded in the **exact file and line numbers** where the code lives — no hallucinated paths or functions. Also drafts a first-pass `README.md` from the repo's structure.

- Language-aware chunking (`RecursiveCharacterTextSplitter`) across 10+ languages, with exact `(start_line, end_line)` metadata per chunk
- Strictly grounded Q&A chain — the LLM only answers from retrieved context and says so when it can't find something
- Dual embedding backends: local `sentence-transformers` (free/offline) or Gemini embeddings, with automatic rate-limit backoff
- **Stack:** LangChain · ChromaDB · Streamlit · Google Gemini (`gemini-2.5-flash`) · GitPython
